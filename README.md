## 项目简介

河北师范大学课程共享计划旨在建立一个开源、免费、高质量的校内课程资料共享平台，帮助同学们打破信息壁垒，更高效地完成学业任务。

本项目受天津大学课程共享计划的启发而建立，致力于收集并共享河北师范大学各学院、各专业的优质课程资源，包括课件、笔记、历年试题及学习指南。

### 项目愿景

建立一个由学生共建、免费开源的校内学习资料库，促进学术交流与互助，让每一位同学都能获得优质的学习资源。

## 资料目录结构

为了保持仓库的整洁与高效检索，请严格按照以下目录结构上传和整理资料：

```text
📦 HBNU-CourseSharing
 ┣ 📂 学院名称
 ┃ ┣ 📂 专业名称
 ┃ ┃ ┣ 📂 年级-课程名称-授课老师
 ┃ ┃ ┃ ┣ 📂 课件
 ┃ ┃ ┃ ┣ 📂 期末复习笔记
 ┃ ┃ ┃ ┣ 📂 历年真题
 ┃ ┃ ┃ ┗ 📄 README.md（学习指南，可包含学习经验、课程组成、老师评价等）
 ┗ 📄 README.md
```

**命名规范**：

- 课程文件夹建议包含年级、课程名和授课教师，例如：`2023-数据结构-张三`
- 文件命名应清晰易懂，避免使用无意义名称
- 推荐使用下划线或连字符代替空格

## 如何参与贡献

本项目的持续运转依赖大家的共同参与。您可以通过以下两种方式加入：

### 方式一：自主上传（推荐）

如果您熟悉 Git 和 GitHub 的基本操作：

1. **Fork** 本仓库到您的个人 GitHub 账户
2. 在您的 Fork 仓库中，按照上述目录结构添加或更新资料
3. 提交 **Pull Request (PR)**，并在描述中简要说明您添加的内容
4. 维护者审核通过后，您的贡献将被合并到主仓库中

### 方式二：资料投递

如果您不熟悉 Git 操作，但手头有优质的课程资料：

- 请将资料直接发送给项目维护者
- 请注明：学院、专业、年级、课程名称及授课教师
- 维护者将负责统一整理、规范化命名并上传至本仓库

## 使用指南

### 浏览资料

您可以通过以下两种方式访问课程资料：

1. **GitHub 网页端**：直接浏览本仓库的文件目录
2. **GitHub Pages**：访问 [https://mukanaan.github.io/HBNU-CourseSharing/](https://mukanaan.github.io/HBNU-CourseSharing/) 查看整理后的资料索引

### 下载资料

- 单个文件：直接点击文件，然后点击右上角的 **Download** 按钮
- 整个文件夹：建议使用 [DownGit](https://minhaskamal.github.io/DownGit/#/home) 等工具批量下载

## 免责声明

1. 本仓库所有资料均由同学自愿分享，仅供**个人学习、交流参考**使用
2. 严禁将本仓库内的任何资料用于**商业盈利**目的
3. 上传资料时，请确保不侵犯教师或学校的知识产权
4. 本仓库不保证所有资料的绝对准确性或为最新版本，请结合课堂内容进行学习
5. 如发现任何侵权内容或包含个人隐私信息的文件，请立即联系维护者，我们将在核实后第一时间进行下架处理

## 常见问题

**Q: 我上传的资料可以被删除吗？**

A: 可以。如果您希望删除自己上传的资料，请提交 Issue 或联系维护者，我们会及时处理。

**Q: 我可以匿名贡献资料吗？**

A: 可以。您可以通过"资料投递"方式匿名贡献，维护者会保护您的隐私信息。

**Q: 资料会永久保存吗？**

A: 我们会尽力维护资料的完整性和时效性，但不保证永久保存。建议重要资料本地备份。
