# 🎓 河北师范大学课程共享计划 (HBNU Course Sharing)

欢迎来到河北师范大学课程共享计划！本项目旨在建立一个开源、免费、高质量的校内课程资料共享平台，帮助同学们更好地学习与交流。

## 📚 项目简介
- **目标**：打破信息差，汇聚校内优质课程资源（课件、笔记、历年参考、学习指南等）。
- **适用人群**：河北师范大学全体在校生及校友。
- **托管平台**：GitHub (支持 GitHub Pages 在线预览)
