# 题型、分值和知识点

一、选择题
10个题，每小题2分，共20分

二、填空题
每空1分，共10分，题目数量不确定大约6，7个

三、简答题，3个题，每题5分
关系代数写查询
两个是简答

四、设计题，2个题，共 25 分
1. 画 E-R 图
2. E-R 转模式
3. DDL
4. 模式规范化和模式分解

五、编程题，6个题，共30分
1. 多表查询
2. DML
3. 存储过程/函数 + 复合语句
4. 触发器
5. 视图
6. DCL（用户管理和权限管理）

# 分值分布

第一部分 基础（70分）
1. 概述
2. SQL 编程
3. 关系代数（10分）

第二部分 设计（20分）

第三部分 原理（10分）
1. 存储管理
2. 索引结构
3. 查询处理
4. 查询优化
5. 并发控制（必考）
6. 故障恢复
